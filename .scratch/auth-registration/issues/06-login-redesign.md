# 06 — 登录页重做

**What to build:** 与注册一致的键盘友好、留白从容、错误内联的登录体验，并让品牌 hero 在聚焦时收缩让位。命主打开登录页：布局与注册同款；输入校验就地；凭证错误在密码框下方就地提示「邮箱或密码错误」，不再弹窗；点进输入框时 `LoginHero`（罗盘/星野/辉光）收缩淡出、把空间让给表单，失焦后恢复；被限流时以 Toast 提示；登录成功自动进入对话主页。登录页的《用户协议》《隐私政策》维持纯说明文案、不做可点（本次范围外）。

**Blocked by:** 05（复用注册先行建立的布局/键盘/校验范式；透过 05 亦已具备 01、02）。

**Status:** ready-for-agent

- [ ] 复用票 05 建立的布局/键盘/校验范式（同款 `flexGrow` 留白 + `avoidKeyboard` + 失焦/提交校验）。
- [ ] `invalid_credentials` 就地内联到密码字段；`rate_limited` / 网络走 Toast；**移除登录的 `Alert.alert`**。
- [ ] 输入聚焦时 `LoginHero` 收缩/淡出（尊重 reduce-motion），失焦恢复。
- [ ] 登录成功由 `RootNav` 依 auth 态自动跳转（现状不变）；提交中按钮态、禁重复点击。
- [ ] 《用户协议》《隐私政策》维持纯文案、不可点。
- [ ] 改版后做一次 iOS + Android 真机视觉核对（软门槛，不阻断）。
