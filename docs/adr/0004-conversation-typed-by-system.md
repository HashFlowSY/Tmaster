# 对话按命理系统分型,八字卡 onboarding、奇门不卡

新建对话时用户二选一(八字 / 奇门),`conversations.system` 一旦创建即固定、不可切换。八字对话依赖命主生辰,因此要求用户先完成 onboarding(无生辰则引导去填);奇门占测按起局的当下时间与所问之事,与出生信息无关,故奇门对话不要求生辰。

## Considered Options

- 单一不分型对话、由 AI 自行判断走八字还是奇门:被否。两系统所需上下文与排盘方式不同(八字注入确定性盘、奇门按时间起局),分型让 prompt 构造与历史注入清晰可控。
- 所有功能统一强制 onboarding:虽简单,但会把「只想用奇门」的用户挡在生辰门槛外,无谓流失。

## Consequences

- 奇门功能可在用户未填生辰时直接使用。
- 一条对话的系统在其生命周期内稳定,`messages` 与盘上下文的绑定无歧义。
